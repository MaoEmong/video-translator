# 14. 포트폴리오 범위

이 프로젝트의 목적은 상용 서비스 전체를 구현하는 것이 아니라, 외국어 영상이 비동기 처리
파이프라인을 거쳐 번역 자막으로 변환되는 과정을 보여주는 것이다.

## 핵심 시연 흐름

```text
영상 업로드
  → signed URL Object Storage 업로드
  → Redis Queue 등록
  → Worker 실행
  → FFmpeg 오디오 정규화
  → OpenAI whisper-1 STT
  → OpenAI gpt-5.6-terra 번역
  → SRT/VTT 생성
  → 자막 편집 및 다운로드
```

## 포트폴리오에서 보여줄 기술 포인트

- HTTP 요청을 차단하지 않는 Queue 기반 비동기 작업 처리
- DB에 작업·단계·번역 버전을 분리해 저장하는 모델링
- OpenAI 호출을 Adapter로 격리하고 JSON Schema 응답을 검증하는 구조
- 원본 파일을 API 서버가 직접 처리하지 않는 signed URL 업로드
- 번역 결과와 표시 시간을 분리해 자막을 편집할 수 있는 구조
- 실패 단계와 외부 API 호출 정보를 추적할 수 있는 데이터 모델

## 의도적으로 제외한 기능

다음은 데모 복잡도를 낮추기 위해 구현 범위에서 제외한다.

- 로그인, 사용자별 권한, multi-tenant 격리
- 장시간 영상 chunk 분할, 화자 분리, 원문 편집
- 실패 작업 자동 재시도와 Idempotency-Key
- 번역 영상 렌더링, 음성 더빙, 실시간 처리
- quota, 결제, 운영 대시보드, 보관 기간 scheduler

## 시연 시나리오

1. `http://127.0.0.1:8000`에 접속한다.
2. 짧은 외국어 영상 파일을 선택하고 목표 언어를 지정한다.
3. 진행률이 `VALIDATING → TRANSCRIBING → TRANSLATING → COMPLETED`로 변하는 것을 보여준다.
4. 생성된 번역문 한두 개와 표시 시간을 수정한다.
5. SRT 또는 VTT 파일을 다운로드해 시간 정보와 줄바꿈을 확인한다.

## 한계 고지

현재 구현은 짧은 데모 영상과 단일 로컬 실행 환경을 기준으로 한다. 상용 운영을 위해서는
인증, 대용량 파일 정책, 재시도, 관측성, 비용 제한을 별도로 추가해야 한다.
