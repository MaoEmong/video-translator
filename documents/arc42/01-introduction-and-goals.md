# 1. 소개와 목표

## 시스템 목적

사용자가 외국어 영상을 업로드하면 음성을 텍스트로 변환하고, 목표 언어로 번역한 뒤, 시간 정보가
유지된 SRT/VTT 자막을 다운로드할 수 있게 한다.

## 포트폴리오 목표

- 긴 작업을 HTTP 요청과 분리하는 비동기 처리 구조를 보여준다.
- 외부 AI 의존성을 Adapter 뒤에 격리한다.
- 원본 자막, 번역 버전, 편집 결과, export 파일을 분리해 모델링한다.
- 파일 업로드와 결과 다운로드를 Object Storage의 signed URL로 처리한다.
- 실제 OpenAI 연동과 mock 기반 자동 테스트를 함께 보여준다.

## 핵심 사용자 시나리오

```text
영상 선택 → 업로드 → 작업 생성 → 진행률 확인 → 번역문 편집 → SRT/VTT 다운로드
```

## 성공 기준

짧은 영상 하나를 업로드했을 때 API가 즉시 작업을 만들고, Worker가 `검증 → 오디오 추출 → STT →
번역 → 자막 생성`을 완료하며, 사용자가 결과 자막을 내려받을 수 있어야 한다.

상세 범위와 데모 시나리오는 [포트폴리오 범위](../14-portfolio-scope.md)에 기록한다.
