# 13. 운영 확장 검토 사항

현재 포트폴리오 MVP에 필요한 핵심 선택은 [ADR](./adr/README.md)에 기록하고 구현했다. 아래 항목은
MVP를 실제 다중 사용자 서비스로 확장할 때 검토할 backlog다. 즉, 현재 구현이 멈춰 있다는 뜻이 아니다.

| 항목 | 기본값 | 결정 필요 |
|---|---|---|
| 인증 | 로컬 단일 사용자 전제 | 운영용 로그인·권한 필요 |
| 최대 영상 크기 | 환경변수로 제한 | 운영 상한과 업로드 정책 필요 |
| 최대 영상 길이 | 짧은 데모 영상 기준 | 장시간 chunking과 비용 정책 필요 |
| 기본 목표 언어 | 한국어 | 제품 지원 언어 정책 필요 |
| 지원 언어 | 설정으로 확장 가능 | 언어별 품질 검증 필요 |
| 출력 형식 | SRT, VTT | ASS 등 추가 형식은 후속 |
| 번역 스타일 | 자연스러운 자막체 | 용어집·스타일 가이드로 확장 |
| 파일 보관 기간 | 로컬 개발 환경 기준 | lifecycle rule과 사용자 고지 필요 |
| STT 모델 | `whisper-1`, ADR-004 | 모델 변경 전 capability 검증 필요 |
| 번역 모델 | `gpt-5.6-terra` | 비용·품질 평가 후 변경 |
| 자막 편집 | 번역문과 표시 시간 구현 | 동시 편집 충돌 제어 필요 |
| 원문 편집 | MVP 제외 | 사용자 요구 확인 후 결정 |
| 화자 분리 | MVP 제외 | diarization provider 검토 |
| 번역 영상 생성 | MVP 제외 | 렌더링 Worker와 비용 검토 |
| 용어집 | MVP 이후 | 도메인별 관리 범위 정의 |

## 운영 확장 전에 정할 항목

1. 최대 영상 크기와 길이
2. 기본 목표 언어와 지원 언어
3. 영상·오디오·결과 파일 보관 기간
4. 인증을 MVP에 포함할지 여부
5. 번역 영상 생성 시점
