# 00. 전체 개요

## 목표

사용자가 외국어 영상을 업로드하면 음성을 텍스트로 변환하고, 지정한 언어로 번역한 뒤 SRT/VTT 자막 파일을 제공한다.

## 핵심 사용자 흐름

```text
영상 업로드
  → 목표 언어 선택
  → 비동기 번역 작업 생성
  → 진행률 확인
  → 자막 검토 및 수정
  → SRT/VTT 다운로드
```

## 설계 원칙

1. 긴 영상 처리는 반드시 비동기로 실행한다.
2. 영상, 원문 Transcript, 번역 작업을 분리한다.
3. 원문 시간 정보는 시스템이 관리하고 번역 LLM은 번역문만 반환한다.
4. OpenAI 호출은 Adapter 계층으로 감싸고 API 서버에서 직접 호출하지 않는다.
5. 모든 단계는 재시작 가능하고 중복 실행에 안전해야 한다.
6. 원본과 각 번역 버전을 보존해 재번역과 편집 이력을 지원한다.

## MVP 포함 범위

- 영상 업로드
- 음성 언어 자동 감지
- 목표 언어 선택
- FFmpeg 기반 오디오 추출
- OpenAI STT
- OpenAI 번역 LLM
- SRT/VTT 생성
- 작업 상태와 진행률 조회
- 자막 세그먼트 편집
- 실패 단계 재시도
- 결과 파일 다운로드

## MVP 제외 범위

- 실시간 음성 인식
- 화자 분리
- 음성 더빙
- 자막 번인 영상 생성
- 번역 메모리와 사용자 용어집
- 다중 목표 언어 일괄 실행

## 기본 가정

- Backend와 Worker는 같은 코드베이스에서 시작한다.
- Object Storage는 private으로 운영한다.
- 원본 Transcript는 다른 목표 언어 번역에서 재사용한다.
- 목표 언어별로 하나의 Translation Job을 만든다.
- 자막 편집은 번역문과 표시 시간만 수정할 수 있도록 시작한다.
